🎯 FUNCIONES PRINCIPALES DISPONIBLES:

    1️⃣  ▶️ INICIAR
        → Comienza la simulación del cruce
        → Los carros empiezan a circular
        → Los semáforos cambian automáticamente

    2️⃣  ⏸️ PAUSAR
        → Detiene todos los movimientos
        → Los carros se quedan donde estaban
        → Permite observar el estado actual

    3️⃣  🔄 REINICIAR
        → Vuelve a empezar desde cero
        → Reinicia contadores de tiempo y ciclos
        → Limpia todos los carros

    4️⃣  SLIDER DE DURACIÓN
        → Ajusta duración del ciclo (2-10 segundos)
        → Se actualiza en tiempo real
        → Afecta la velocidad de los cambios de semáforo

🔄 CICLO DE SINCRONIZACIÓN (20 segundos totales):

    Fase 0: NORTE-SUR VERDE (8 segundos)
            └─ Los carros circulan en dirección norte-sur
            └─ Carros este-oeste esperan en rojo

    Fase 1: NORTE-SUR AMARILLO (2 segundos)
            └─ Transición - carros desaceleran

    Fase 2: ESTE-OESTE VERDE (8 segundos)
            └─ Los carros circulan en dirección este-oeste
            └─ Carros norte-sur esperan en rojo

    Fase 3: ESTE-OESTE AMARILLO (2 segundos)
            └─ Transición - carros desaceleran
            └─ Vuelve a Fase 0

    ⚠️ GARANTÍA: N-S y E-O NUNCA están en VERDE simultáneamente ✅

💡 TIPS Y TRUCOS:

    1. Si quieres ver el log detallado:
       → Abre la consola del navegador (F12)
       → Ve a la pestaña "Console"

    2. Si quieres modificar algo:
       → Los cambios en src/ se aplican automáticamente (hot reload)
       → No necesitas reiniciar

    3. Para cambiar duraciones:
       → Edita TrafficController.js (línea 42-47)
       → Modifica el array phaseConfig

    4. Para cambiar velocidad de carros:
       → Edita VehicleManager.js (línea 25)
       → Cambia this.speed = 2

🛠️ SI ALGO NO FUNCIONA:

    ❌ "Página en blanco"
       → Presiona F5 (refresca la página)
       → Abre consola (F12) para ver errores

    ❌ "WebSocket desconectado"
       → Verifica que ambas terminales estén abiertas
       → Revisa que no haya errores en la consola

    ❌ "Puerto 3001 en uso"
       → Cierra lo que esté usando ese puerto
       → O usa PORT=3002 npm run client

    ❌ "Dependencias faltando"
       → npm install
       → npm install --legacy-peer-deps (si hay conflictos)
